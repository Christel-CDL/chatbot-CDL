# Assistant CDL Expertises – Registre de nuisances

Page web du chatbot « Registre de nuisances clé en main » de CDL Expertises, publiée sur https://chat.cdl-expertises.com (GitHub Pages).

- `index.html` : fenêtre de chat autonome. Les messages sont envoyés au scénario Make « Fil rouge P3 – Agent IA chatbot + formulaire », qui interroge l'agent IA (FAQ et offres stockées dans Airtable) et renvoie la réponse.
- `CNAME` : domaine personnalisé `chat.cdl-expertises.com` (entrée CNAME chez OVH vers `christel-cdl.github.io`).
- Aucune donnée personnelle n'est stockée dans ce dépôt.

Projet réalisé dans le cadre du fil rouge de la formation IA Alegria.
